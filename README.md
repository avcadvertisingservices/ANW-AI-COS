# ANW AI-COS

**Acoustic Neuroma Warrior AI Content Operating System**

ANW AI-COS is the private AI-powered operating system behind the Acoustic Neuroma Warrior platform. It automates topic discovery, content generation, repurposing, publishing preparation, community intelligence, and performance analysis while keeping the founder in control through review and approval.

## Mission

**You Are Not Alone.**

To build a trusted, survivor-led digital education and support ecosystem for people affected by acoustic neuroma, including patients, survivors, caregivers, and families.

## Operating Principle

> Review → Approve → Publish

## Core Architecture

- **WordPress + Elementor** — Public website
- **Next.js** — Future private dashboard
- **Supabase** — Master database
- **Make.com** — Automation
- **Google Drive** — Media storage
- **Notion** — Project management
- **GitHub** — Source of truth for code and technical documentation
- **ChatGPT** — Product strategy, architecture, and content intelligence
- **Codex** — Software development and implementation
