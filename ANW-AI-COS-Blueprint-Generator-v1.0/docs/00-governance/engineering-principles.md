# Engineering Principles

1. Plan before implementation.
2. Document architecture and interfaces.
3. Build small, testable modules.
4. Keep GitHub as the technical source of truth.
5. Use Supabase as the primary application backend.
6. Use WordPress + Elementor for the public website.
7. Use Next.js for future applications.
8. Use Make.com for workflow automation.
9. Use Google Apps Script only for Google Workspace integration and automation.
10. Require human review for medical or high-risk content.
