# Enterprise Architecture

## Primary architecture

- Public website: WordPress + Elementor
- Future web applications: Next.js
- Backend: Supabase
- Workflow automation: Make.com
- Google Workspace automation: Google Apps Script
- High-volume processing: Google Cloud Run
- Source control and technical documentation: GitHub
- Project management: Notion
- Media storage: Google Drive and Supabase Storage as appropriate

## Core layers

1. Experience
2. Content
3. Intelligence
4. Data
5. Integration
6. Automation
7. Governance and operations
