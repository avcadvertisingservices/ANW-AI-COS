# Sprint 09 — Prompt Library v1.0

## Purpose

Provides reusable, versioned prompts for ANW AI-COS.

## Included prompts

- Educational blog
- Facebook post
- Reel script
- Six-slide carousel
- SEO metadata
- Community reply

## Built-in controls

- ANW mission and brand voice
- Medical safety rules
- Content safety rules
- Required-variable validation
- Prompt versioning
- Active/inactive prompt registry
- Template rendering
- Automated tests

## Important

Prompts generate drafts only. Medical content still requires human review and source verification.
