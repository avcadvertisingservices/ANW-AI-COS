# 07 — Automation Workflows

## A — Topic Discovery
Schedule → collect signals → deduplicate → classify → score → save → notify approval dashboard.

## B — Content Generation
Approved topic → research brief → generate formats → quality checks → save drafts → notify founder.

## C — Website Draft
Approved article → categories/tags → WordPress draft → media → SEO metadata → preview link.

## D — Social Draft
Approved content → caption/media package → scheduling record → final approval.

## E — Analytics
Published content → collect metrics → normalize → save snapshot → update performance score.

## F — Repurposing
Performance threshold → identify winning attributes → generate new angles → create candidates → approval.

## G — Community Intelligence
Comments/questions → classify → detect repeats → draft safe response → escalate sensitive items → create topics.

## H — Media Organization
Approved asset → correct Google Drive folder → metadata in Supabase → link to content.

## Failure Handling
Retry policy, error log, failed status, owner notification, idempotency, and manual recovery procedure are mandatory.
