# 16 — Governance and Versioning

## Source of Truth
GitHub is authoritative for architecture, code, migrations, prompt specifications, and technical documentation. Notion is for project management, sprints, tasks, approvals, and notes.

## Versioning
Semantic Versioning:
- MAJOR: incompatible architecture/workflow changes
- MINOR: backward-compatible features
- PATCH: fixes and documentation corrections

## Change Control
Propose → review impact → update documentation → implement → test → approve → release → update changelog.

## Owner
AVC Advertising Services retains final ownership and approval authority.
