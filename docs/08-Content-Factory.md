# 08 — Content Factory

## Automatic Topic Sources
Facebook performance, comments, website gaps, FAQs, trusted medical updates, seasonal events, evergreen plans, founder story library, and existing content archive.

## Output Package
Website article, Facebook post, 30-second reel, 60-second reel, carousel, Pinterest copy, email, SEO title, meta description, CTA, hashtags, image prompt, media suggestions, reply templates, and future angles.

## Status Flow
`candidate → approved_topic → researching → drafting → review → approved → scheduled → published → measured → repurpose_candidate → archived`

## Quality Gates
Mission fit, factual support, no fabricated personal details, appropriate disclaimer, platform fit, brand voice, accessibility, duplication check, and approval record.
