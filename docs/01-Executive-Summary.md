# 01 — Executive Summary

ANW AI-COS supports two connected products:

1. **Public website** — a trusted, searchable educational and support platform.
2. **Private operating system** — an internal engine for topic discovery, content generation, approval, publishing preparation, analytics, repurposing, and community intelligence.

## Primary Business Objective

Grow and monetize the Acoustic Neuroma Warrior Facebook Page while building permanent website value from every approved content asset.

## Primary User Experience

**Open dashboard → Review recommendations → Approve → System prepares drafts and publishing actions**

## Version 1 Success
- Automatic topic generation and ranking
- Multi-format content packages
- Supabase storage
- Google Drive media organization
- WordPress draft preparation
- Facebook workflow support
- Winner detection and repurposing
- Safe reply drafting with human approval
