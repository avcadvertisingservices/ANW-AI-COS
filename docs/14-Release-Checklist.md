# 14 — Release Checklist

## Planning
- [ ] Scope and acceptance criteria approved
- [ ] Risks and dependencies recorded

## Architecture
- [ ] Blueprint updated
- [ ] Security and database impact reviewed
- [ ] Rollback defined

## Development
- [ ] Code reviewed
- [ ] No secrets committed
- [ ] Configuration and migrations documented

## Testing
- [ ] Unit, integration, permission, accessibility, mobile, publishing, and recovery tests passed

## Content Safety
- [ ] Medical claims sourced
- [ ] Personal experience labeled
- [ ] Sensitive replies require approval
- [ ] Disclaimers present

## Deployment
- [ ] Backup complete
- [ ] Environment variables verified
- [ ] Monitoring enabled
- [ ] Rollback tested
- [ ] Release notes complete

## Approval
- [ ] Founder approval
- [ ] Technical certification
- [ ] Version tag and changelog updated
