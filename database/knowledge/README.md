# Knowledge Data

This folder holds source-backed knowledge datasets.

## Important rules

1. Keep new medical records in `draft`.
2. Add traceable source IDs.
3. Mark medical content with `medicalReviewRequired: true`.
4. Do not change a medical record to `approved` until its review is complete.
5. Do not use community stories as medical evidence.
6. Separate personal experience from general medical education.
7. Never include private patient-identifying information without explicit consent.

`knowledge-template.json` is a structural template only. It does not contain medical guidance.
